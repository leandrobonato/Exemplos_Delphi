## 📖 Sobre o repositório

Este repositório reúne dezenas de exemplos práticos desenvolvidos e estudados ao longo do tempo, servindo como **material de referência** e **portfólio técnico**. Cada pasta é um exemplo autocontido, geralmente com o código-fonte em `Fontes/` (ou na própria raiz da pasta).

Os temas vão de recursos básicos da linguagem até tópicos avançados como **Clean Architecture**, **RTTI**, **threads**, **gerenciamento de memória**, **APIs escaláveis** e **apps mobile completos**.

> 💡 **Como abrir um exemplo:** abra o arquivo `.dproj` (projeto) ou `.dpr` (source do projeto) da pasta desejada no **RAD Studio / Delphi**. Projetos com backend Node.js exigem `npm install` na respectiva pasta.

## 🧰 Tecnologias e conceitos abordados

- **Linguagem:** Object Pascal (Delphi)
- **Frameworks UI:** VCL (Desktop) e FireMonkey/FMX (Android, iOS, Windows, macOS)
- **Backend/Web:** Horse (framework web Delphi), Node.js/Express (alguns backends)
- **Bancos de dados:** Firebird, SQLite, MySQL — via FireDAC
- **APIs & Rede:** REST, JSON, sockets, integração com serviços de nuvem (AWS)
- **Arquitetura:** Clean Architecture, MVC, injeção de dependência, RTTI
- **Qualidade:** gerenciamento de memória, threads, refatoração, boas práticas

## 🚀 Como executar

1. Instale o [RAD Studio / Delphi](https://www.embarcadero.com/products/delphi) (versão 10.x ou superior recomendada).
2. Clone o repositório:
   ```bash
   git clone https://github.com/<seu-usuario>/Exemplos_Delphi.git
   ```
3. Abra o arquivo `.dproj` do exemplo desejado no RAD Studio.
4. Para exemplos **mobile**, configure o SDK Android/iOS no Delphi.
5. Para backends **Node.js**, entre na pasta do backend e rode `npm install` seguido de `npm start`.
